# repunch-web

# 개요
- 원단 거래 플랫폼 서비스
- 개발용 웹 : http://test.repunch.io/

# 사용
```
npm i
npm run dev
```

# 프로젝트 계획
- v1
  - 기본적인 기능 구현
  - paypal 결제 연결
  - 셀러센터
- v2
  - SSR적용하여 각 원단 상품 검색엔진에 노출시키기
  - 상품 거래에대한 invoice를 pdf로 변환 및 다운 기능 구현
  - 페이지 별 뷰 카운트 관리

# 기술 스텍 및 라이브러리
- Next.js
- Typescript
- Styled-component
- Axios
- Redux-toolkit
