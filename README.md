# Repunch - 잔여 원단 구매, 판매 플랫폼 서비스

# 개요
- 공장에서 사용하고 남은 원단들을 거래할 때 서로 연락하고 엑셀파일을 주고받는 등 여러 절차를 간소화하는 서비스입니다.
- 구매자는 상품을 구매 할 수 있으며 배송 상태, 거래 내역을 확인 할 수 있습니다. 판매자는 상품을 등록 및 관리할 수 있습니다.
- 개발 서버를 배포하고 페이팔 결제까지 구현 하였으나 실제 서비스 되지 못하고 중단되었습니다.

# 프로젝트 일정
- 2022.12 ~ 2024.07 중단
